# Brand reference images

The 16 brand marks in `public/assets/brands/` identify editorial style references. They are not Wearwell artwork, endorsements, or evidence that the user owns these brands.

Exact source URLs are retained in `public/assets/brands/sources.json`; runtime paths are in `src/data/brand-images.js`. Images are served locally, with meaningful alt text and contained dimensions.

- COS, ARKET: logo symbols extracted from the official site's SVG sprite.
- A.P.C., Carhartt WIP, Stüssy, GANNI, Reformation: logo SVG paths extracted from official page markup.
- TOTEME, The Row, Acne Studios, Arc’teryx, Patagonia: official logo image assets.
- Polo Ralph Lauren: official corporate media-assets library, https://corporate.ralphlauren.com/logos.
- Theory and UNIQLO: public-domain text-logo files hosted on Wikimedia Commons. Source descriptions: https://commons.wikimedia.org/wiki/File:Theory_(Clothing)_Logo.svg and https://commons.wikimedia.org/wiki/File:UNIQLO_logo.svg.
- Sézane: logo from its investor's company profile, https://www.summitpartners.com/companies/sezane.

Downloaded September 24, 2026. Original marks remain the respective brands' property; displayed only for identification. Artwork geometry has not been redrawn or generated.
